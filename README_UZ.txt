HISOBIM PRO — boshlang‘ich ishlaydigan versiya

FUNKSIYALAR
- Shaxsiy va biznes hisoblarini alohida yuritish
- UZS, USD, RUB valyutalarida yozuv kiritish
- Kirim, chiqim, qarz olish va qarz berish
- Qarzning qisman/to‘liq qaytarilishini hisoblash
- Kunlik/oylik/barcha vaqt hisobotlari va xarajat kategoriyalari
- JSON zaxira nusxasi va tiklash
- CSV eksport (Excel orqali ochiladi)
- Offline ishlash uchun PWA kesh

ANDROIDDA SINASH / O‘RNATISH
1. Papkani HTTPS qo‘llaydigan hostingga joylashtiring (yoki lokal tarmoqda test server ishga tushiring).
2. Android Chrome orqali saytni oching.
3. Brauzer menyusidan “Add to Home screen” / “Install app” ni tanlang.
4. Ilova bosh ekranga o‘rnatiladi va birinchi yuklanishdan keyin offline ishlashi mumkin.

MUHIM
Bu ZIP hozircha ilovaning PWA manba fayllaridir, tayyor APK emas. APK yig‘ish uchun Android SDK va Gradle build muhiti kerak. Ushbu ish muhitida Android SDK/Flutter mavjud emas, shuning uchun APK deb noto‘g‘ri ko‘rsatilmadi.

MA’LUMOTLAR
Yozuvlar shu qurilmaning brauzer LocalStorage xotirasida saqlanadi. Brauzer ma’lumotlarini tozalashdan oldin Hisobot bo‘limidan zaxira nusxasini oling. Hozircha avtomatik bulut sinxronizatsiyasi ulanmagan; internet orqali zaxiralash keyingi bosqichda server yoki bulut xizmatiga ulashni talab qiladi.
